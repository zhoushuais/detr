## best_selection_metric 语义确认
- `configs/monodetr.yaml:16` 的 `dataset.best_selection_metric` 只控制 `checkpoint_best` 的选帧规则，不影响训练类别/损失。
- 可选值仅两个（定义于 `lib/datasets/kitti/evaluation_protocol.py: BEST_SELECTION_METRICS`）：
  - `car_moderate_3d_r40` -> 取 Car 的 Moderate AP_R40 3D
  - `mean3_moderate_3d_r40` -> 取 Car/Pedestrian/Cyclist 三类 Moderate AP_R40 3D 的算术平均
- 调用链：config -> `KITTI_Dataset.__init__`(kitti_dataset.py:36) -> `eval()`(kitti_dataset.py:104-127) -> `select_best_score()` -> `tester_helper.evaluate()`(tester_helper.py:134) -> `trainer_helper` 中 `cur_result > best_result` 存 `checkpoint_best`。
- 注意：`mean3` 要求 `writelist` 同时包含三类；`car` 要求包含 Car，否则 `select_best_score` 抛 ValueError。
