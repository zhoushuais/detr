- 新分支P2（从v0-baseline创建）

- P2新方向：RARE-style K假设深度预测（CVPR 2026）
  - 核心思路：depth_embed头从输出1个假设改为K个假设，用winner-take-all训练+多样性正则化防止坍缩
  - 原理：直接解决单目3D检测的深度歧义问题，通过多假设覆盖不同可能的深度解
  - 来源：RARE (CVPR 2026 Highlight), Cyclist +39%
- 配套改进：无，保持原始 baseline
- 备选方案：MonoCoP链式预测 (CVPR 2026)，Salience DETR尺度无关显著性 (CVPR 2024)
- 实施路线：K假设核心 → 完善ranking loss → 备选方案
